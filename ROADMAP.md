# Roadmap

This describes intent for the next ~12 months (last updated 2026-08).

## Planned

- **New service lines** — expand the service catalogue beyond the current
  offering (Application Security, SecDevOps, IT Security, AI Security,
  security advice). Specific new lines will be added to the homepage as
  they're finalized.
- **OpenSSF Best Practices — Silver tier by Q4 2026.** Baseline-level work
  is in progress now (see [README.md](README.md) badges for live status).

## Explicitly out of scope

- **No client portal.** No login area, no account system, no in-browser
  project dashboard. Contact and booking stay routed through
  [cal.com/securelayer](https://cal.com/securelayer); this stays a static
  informational site with no backend and no stored user data.

## Notes

This roadmap reflects intent, not a guarantee — dates and scope may shift.
See [CHANGELOG.md](CHANGELOG.md) for what's actually shipped.
